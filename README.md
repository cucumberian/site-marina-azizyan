# Страница художницы — Марина Азизян

Лёгкая персональная страница без сборки и зависимостей: HTML + CSS + немного vanilla JS.
Оформление в духе референса [robbietilton.com/more-info](https://robbietilton.com/more-info) —
много воздуха, серая типографика, карусель работ, тусклые подписи, которые оживают при наведении.

## Как открыть

Просто открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8080      # http://localhost:8080
```

Есть также **`site.html`** — ровно та же страница, но одним файлом: стили, скрипты и
картинки вшиты внутрь (7,6 МБ). Её можно переслать по почте или открыть с флешки —
никаких соседних папок не нужно. Обновляют так же: после правок в `index.html`
или изображении запустить `python3 tools/build_standalone.py`.

Служебный параметр `?static=1` показывает все секции сразу и без анимаций —
удобно для печати и скриншотов.

## Что на странице

| Секция | Содержание |
|---|---|
| Шапка + герой | имя, род занятий, награды, карусель «Избранное» (9 работ, точки и стрелки) |
| О себе | портрет (клик — на весь экран), биография, сворачиваемый блок «читать полностью» |
| Цитата | «Когда художник рисует, рука может чуть-чуть сдвинуться в сторону…» |
| Работы | 4 галереи: живопись и графика · лоскутное шитьё · эскизы к фильму «Нос» · рисунки к «Дон Жуану» (по 8 карточек + «показать все») |
| Фильмы и спектакли | кино, театр, балет и опера, выставки |
| Альбомы работ | обложки альбомов со страницы художницы |
| О художнице | ссылки на публикации |
| Связаться + подвал | Facebook, ВКонтакте, интервью |

Клик по карточке открывает лайтбокс; `←` `→` листают внутри серии, `Esc` закрывает.

## Файлы

```
index.html              страница
assets/css/style.css    оформление
assets/js/app.js        карусели, сетки, лайтбокс, «читать полностью», появление секций
assets/js/data.js       данные галерей (генерируется)
assets/web/             изображения для веба — все в WebP: полный размер, preview/ (карточки), medium/ (лайтбокс в site.html), обложки альбомов
assets/web/manifest.json список изображений
assets/img/             исходники в полном разрешении (не для отправки на сайт)
tools/build_images.py   сжатие исходников в assets/web
tools/build_data.py     сборка assets/js/data.js из манифеста
tools/build_standalone.py  сборка site.html (страница одним файлом)
```

Поменяли картинки — пересоберите данные:

```bash
python3 tools/build_images.py && python3 tools/build_data.py
```

Список работ и подписей к галереям правится в `tools/build_images.py` (массив `STUDIO`)
и в `tools/build_data.py` (`SECTIONS`).

## О чем стоит спросить хозяйку страницы

1. **Контакты.** Сейчас ссылка ведёт на Facebook — можно заменить на e-mail или телефон.
2. **Альбомы.** Обложки взяты со страницы в Facebook, названия и число работ — оттуда же; ссылки ведут на общий список альбомов. Если нужны прямые ссылки на каждый альбом — пришлите их.
3. **Подписи к работам.** У эскизов сейчас общие подписи («Эскиз к м/ф „Нос“ · 3»). Если есть названия листов и даты — подставим.
4. **Портреты.** Фото Марины Цолаковны взяты из статьи «Культуры Петербурга»; если есть её собственный портрет — заменим.
5. **Раздел «Выставки».** Персональные выставки 1994–2012 упомянуты списком — стоит уточнить названия и годы.
