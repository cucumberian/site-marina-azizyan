# Страница художницы — Марина Азизян

Лёгкая персональная страница без сборки и зависимостей: HTML + CSS + немного vanilla JS.
Оформление в духе референса [robbietilton.com/more-info](https://robbietilton.com/more-info) —
много воздуха, серая типографика, карусель работ, тусклые подписи, которые оживают при наведении.

## Как открыть

Просто открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8080      # http://localhost:8080
```

Служебный параметр `?static=1` показывает все секции сразу и без анимаций —
удобно для печати и скриншотов.

## Что на странице

| Секция | Содержание |
|---|---|
| Шапка + герой | имя, род занятий, награды |
| О себе | портрет (клик — на весь экран), биография, сворачиваемый блок «читать полностью» |
| Цитата | «Когда художник рисует, рука может чуть-чуть сдвинуться в сторону…» |
| Работы | 4 галереи: живопись и графика · лоскутное шитьё · эскизы к фильму «Нос» · рисунки к «Дон Жуану» (одна строка миниатюр + «показать все») |
| История | хронология: учёба у Акимова, 25 фильмов «Ленфильма», театр и балет, премии, персональные выставки |
| Альбомы работ | обложки альбомов; клик — весь альбом открывается в лайтбоксе; исходники — в `images/albums/` |
| Лента новостей | последние интервью и события со ссылками на источники |
| О художнице | Википедия, Кинопоиск, публикации |
| Подвал | Facebook, «наверх» |

Клик по карточке открывает лайтбокс; `←` `→` листают внутри серии, `Esc` закрывает.

## Файлы

```
index.html              страница
assets/css/style.css    оформление
assets/js/app.js        карусели, сетки, лайтбокс, «читать полностью», появление секций
assets/js/data.js       данные галерей (генерируется)
assets/web/             изображения для веба — все в WebP: полный размер и preview/ (карточки), обложки альбомов
assets/web/manifest.json список изображений
images/                 исходники JPG в полном разрешении (sp*.jpg и albums/<год>-<название>/<NN>.jpg)
tools/                  локальные тулзы сборки — в .gitignore, интерфейс описан в AGENTS.md
_config.yml             публикация GitHub Pages: exclude служебных файлов (README, AGENTS)
```

Картинки `images/` и `tools/` в git не входят; служебные файлы репозитория
(`README.md`, `AGENTS.md`) на сам сайт не попадают — исключены в `_config.yml`.
Публикация идёт из репозитория как есть (GitHub Pages, Jekyll). Поменяли картинки — пересоберите данные:

```bash
python3 tools/build_images.py && python3 tools/build_data.py
```

Список работ и подписей к галереям правится в `tools/build_images.py` (массив `STUDIO`)
и в `tools/build_data.py` (`SECTIONS`). Скриптов нет — восстановить по описанию
интерфейса в `AGENTS.md`.

## О чем стоит спросить хозяйку страницы

1. **Контакты.** Секция «Связаться» пока убрана полностью; чтобы вернуть — нужны контакты (e-mail, телефон или страница).
2. **Альбомы.** Ссылки на Facebook убраны, исходники альбомов лежат в `images/albums/`; при желании можно вывести их галереями на странице.
3. **Подписи к работам.** У эскизов сейчас общие подписи («Эскиз к м/ф „Нос“ · 3»). Если есть названия листов и даты — подставим.
4. **Портреты.** Фото Марины Цолаковны взяты из статьи «Культуры Петербурга»; если есть её собственный портрет — заменим.
5. **Раздел «Выставки».** Персональные выставки 1994–2012 упомянуты списком — стоит уточнить названия и годы.
